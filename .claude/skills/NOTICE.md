# Source

These 12 skills (`omarchy-bar-widget`, `omarchy-panel-overlay`,
`omarchy-plugin-debug`, `omarchy-plugin-demo`, `omarchy-plugin-design`,
`omarchy-plugin-migrate`, `omarchy-plugin-publish`, `omarchy-plugin-release`,
`omarchy-plugin-scaffold`, `omarchy-plugin-test`, `omarchy-qml-patterns`,
`omarchy-service-ipc`) are vendored, unmodified, from the `skills/` directory
of the native Claude Code plugin archive in
[tcballard/build-omarchy-plugins](https://github.com/tcballard/build-omarchy-plugins)
release [v0.3.1](https://github.com/tcballard/build-omarchy-plugins/releases/tag/v0.3.1)
(`build-omarchy-plugins-claude-plugin-0.3.1.zip`,
sha256 `7b78f2a613981a7110affc86c1cdbd7bcddc455199d55aea4b7d71da9c775652`),
MIT licensed — see [LICENSE](LICENSE).

They give Claude Code (or another skill-aware agent) working in this repo
authoring guidance for Omarchy Quattro shell plugins: bar widgets, panels,
services/IPC, QML patterns, scaffolding, testing, debugging, and marketplace
publishing.
